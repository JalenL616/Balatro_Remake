# Balatro Remake

A solo, private remake of Balatro (a poker-based roguelike deckbuilder) in the browser with React, built in weekly sprints as a learning project. Nothing is built yet; the docs below are Draft v0.

- [`docs/00_charter.md`](docs/00_charter.md): intent, scope, constraints, goals, success criteria, decisions
- [`docs/01_workflow.md`](docs/01_workflow.md): how specs, tests, pairing, experiment branches and sprints work
- [`docs/02_roadmap.md`](docs/02_roadmap.md): chunk order, what to settle before sprint 1, parked ideas
- [`docs/03_research_notes.md`](docs/03_research_notes.md): sources and confidence behind the choices
